Levels are command-oriented and can be entered from 1–255. Vanilla enchantment definitions have maximum levels (for example, Sharpness 5), but Java's enchantment data model allows an enchantment max_level up to 255; using values beyond the normal gameplay maximum can create over-leveled command items. Java uses the modern item-component syntax. Bedrock generates a /give command plus /enchant commands because Bedrock's documented /enchant command applies enchantments to the player's selected item.
